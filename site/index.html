Installiert wird mit dem ACMP MCP

Der ACMP MCP verbindet eure KI mit der ACMP Public API. Ihr fragt in normaler Sprache, die KI holt die Antwort aus ACMP. Die Vorlagen hier sind eine Sache, die damit geht.

Fragen statt klicken
Clients, Software, Schwachstellen, BitLocker, Tickets und Assets. „Wo ist 7-Zip drauf?“ reicht.
Client Commands und Kiosk
Entwürfe anlegen, vorhandene Commands als neue Version korrigieren, freigeben, Kiosk-Einträge pflegen.
Vier-Augen-Freigabe
Was etwas ändert, läuft erst nach Zustimmung auf der Freigabe-Seite. Wie viele zustimmen müssen, stellt ihr pro Tool ein.
Läuft bei euch
Eine Windows-EXE auf dem ACMP-Server. Kein IIS, keine Cloud, jede KI mit MCP-Unterstützung.

Eigene Commands beitragen

Jede Vorlage ist eine lesbare JSON-Datei. Ihr lest euren Command mit dem MCP aus und wandelt ihn um. Kennwörter, Konten und interne Pfade werden dabei entfernt oder zu Parametern. Die Prüfung läuft automatisch, danach schaut ein Mensch drüber.

node tools/from-decode.mjs mein-command.decode.json --id mein-command --category Wartung
node tools/build.mjs --check
